## Projekte

**Digitaler Notfallpass** (Mitwirkender)
Notfallpass mit QR-Code, über den Ersthelfer und Rettungskräfte schnell an lebenswichtige Gesundheitsdaten kommen. Identitätsprüfung über Personalausweis und AusweisApp, DSGVO-konforme Datenverwaltung, Abruf direkt im Browser.

**Newsagent** (eigenes Projekt)
Lokaler Nachrichten-Agent für Windows. Er bewertet Marktnachrichten mit einem lokalen Ollama-Modell nach ihrer voraussichtlichen Marktauswirkung, schickt die relevanten per Telegram und lernt aus 👍/👎-Bewertungen, was wichtig ist.

**Animanymals** (für einen Freund gebaut)
Landingpage für einen Halter exotischer Kleintiere, gebaut mit Next.js, TypeScript und Tailwind CSS v4. Kein Webshop: Jedes Angebot zeigt eine Preisklasse und öffnet eine vorformulierte E-Mail an den Verkäufer.
Live: [animanymals.com](https://animanymals.com)

## Über dieses Repository

Die Seite besteht aus einer einzigen Datei, `index.html`, ohne Framework und ohne Build-Schritt. Alle Screenshots sind direkt als Base64 in die HTML-Datei eingebettet, deshalb gibt es keinen separaten Bilder-Ordner.

**Lokal ansehen:** `index.html` im Browser öffnen.

**Veröffentlichen:** Änderungen in den `main`-Branch pushen. GitHub Pages stellt die Seite nach ein bis zwei Minuten automatisch unter `https://marek-althueser.github.io` bereit.
